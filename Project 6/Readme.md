# 📖 Personal Journal Manager

A simple **Object-Oriented Python** application that allows users to manage their personal journal through a command-line interface. The project demonstrates the use of **file handling**, **exception handling**, and **Object-Oriented Programming (OOP)** concepts in Python.

---

## 📌 Project Overview

The Personal Journal Manager enables users to:

- Add new journal entries
- View all saved entries
- Search journal entries by keyword or date
- Delete all journal entries
- Store data permanently using a text file

The project is menu-driven and designed to demonstrate Python's file handling capabilities while following OOP principles.
