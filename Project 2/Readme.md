# Pattern Generator and Number Analyzer

## 📌 Project Description

A menu-driven Python application that allows users to generate patterns and analyze numbers within a given range.

---

## 🚀 Features

- Generate patterns using:
  - Asterisk (*)
  - Hash (#)
  - Dollar Sign ($)
  - Numbers
- Analyze numbers in a given range
- Identify Even and Odd numbers
- Calculate the Sum of numbers
- Menu-driven interface
- Exit option

---

## 🛠 Technologies Used

- Python
- Loops
- Match-Case
- Conditional Statements
- User Input Handling
