# Pattern Generator and Number Analyzer

## 📌 Project Description

This is a simple Python menu-driven application that allows users to:

- Generate different types of patterns
- Analyze a range of numbers
- Exit the program

The project demonstrates the use of:

- Variables and Data Types
- User Input
- Control Structures
- Loops
- Match-Case Statements
- Nested Loops
- Menu-Driven Programming

---

## 🚀 Features

### 1. Pattern Generator
Users can generate patterns using:

- Asterisk (*)
- Hash (#)
- Dollar Sign ($)
- Number Pattern

Users can also choose the number of rows for the pattern.

### 2. Number Analyzer
For a given range of numbers, the program:

- Identifies whether each number is Even or Odd
- Calculates the Sum of all numbers in the range

### 3. Exit Option
Allows users to safely terminate the program.
