# 🧑‍💻 Personal Data Collector

A beginner-friendly Python project that collects personal information from users and demonstrates basic Python concepts such as:

* User Input
* Data Types
* Type Conversion
* Memory Addresses using `id()`
* Variables
* Arithmetic Operations
* Formatted Output

## 📌 Project Description

This program interacts with the user and collects:

* Name
* Age
* Height
* Favourite Number

After collecting the information, it displays:

* The entered values
* Their respective data types
* Their memory addresses
* An approximate birth year calculation

This project was created as part of my AI/ML & Data Science learning journey.

## 🚀 Features

✅ Takes user input interactively

✅ Demonstrates Python data types (`str`, `int`, `float`)

✅ Shows memory addresses using `id()`

✅ Calculates approximate birth year

✅ Beginner-friendly and easy to understand
