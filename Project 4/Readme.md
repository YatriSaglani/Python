# 📊 Functional Treat - Student Data Analyzer and Transformer Program

## 📌 Overview

Functional Treat is a menu-driven Python application that demonstrates the use of different types of functions and functional programming concepts in Python. The program allows users to input numerical data and perform various operations such as data analysis, sorting, filtering, and factorial calculation.

This project is designed to showcase concepts like:

* User-defined Functions
* Recursion
* Lambda Functions
* Built-in Functions
* Variable Length Arguments (`*args`)
* Keyword Arguments (`**kwargs`)
* Returning Multiple Values

---

## 🚀 Features

### 1️⃣ Input Data

* Accepts multiple integer values from the user.
* Stores the values in a list for further processing.

### 2️⃣ Display Data Summary

Displays:

* Total number of elements
* Minimum value
* Maximum value
* Sum of all values
* Average value

### 3️⃣ Calculate Factorial

* Uses **recursion** to calculate the factorial of a number entered by the user.

### 4️⃣ Filter Data by Threshold

* Uses **lambda** and **filter()** functions.
* Displays all values greater than the threshold entered by the user.

### 5️⃣ Sort Data

Provides:

* Ascending Order Sorting
* Descending Order Sorting

### 6️⃣ Dataset Statistics

Returns and displays:

* Minimum Value
* Maximum Value
* Total Sum
* Average

### 7️⃣ Program Information

Uses **keyword arguments (`**kwargs`)** to display project information.

### 8️⃣ Exit Program

Safely terminates the application.
